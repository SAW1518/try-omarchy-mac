Once I asked which keyboard layout they wanted, and they rejected the question: the answer was in a photo they had already left in the shared folder.

**Why:** they prepare context ahead of time and dislike questions whose answer is already there.
**How to apply:** before asking, look through `~/bypass` and this project (`assets/`, `memory/`) and decide from that. Ask only about what is really missing, with short questions.

They also want memory and context to stay **inside this project**, not in `~/.claude` or anywhere else (see the `project-memory` skill), and the project to be publishable to git with nothing personal in it.
